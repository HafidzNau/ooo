# Portofolio Hafidz Naufal Akbar (Next.js)

## Jalankan lokal
npm install
npm run dev   # buka http://localhost:3000

## Deploy ke Vercel
1. Push folder ini ke repository GitHub.
2. Buka vercel.com > Add New > Project > pilih repository.
3. Framework otomatis terdeteksi sebagai Next.js. Klik Deploy.

Edit data profil di bagian atas app/page.js.
